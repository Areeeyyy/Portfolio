About Me

Hello! I'm a Computer Science student and aspiring Data Engineer based in West Java, Indonesia. Holding an EF SET C1 Advanced English certification, I work on automated workflows, data analysis, and AI features that have to ship, not slide-deck demos.

My journey into data started with automating daily data entry for a freelance client using Advanced Spreadsheets and VBA. That project was the first time I saw what a one-click pipeline can do to a one-hour manual task, and it shaped how I approach work since.

I am an undergraduate at Universitas Gunadarma, focused on Data Engineering and Machine Learning. Most of my current work sits on Google Cloud Platform (GCP) and ranges from automated data pipelines to deep learning and LLM-driven analyses.
