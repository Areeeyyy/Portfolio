## Overview

![WashGo Booking Flow](/assets/image/1_washgo.png)
*The WashGo booking flow, including the optional AI dirt analysis upload step.*

**WashGo** is a full-stack web application for booking on-demand vehicle wash services. Customers can schedule a home-service wash, pick a package (Exterior Only or Bundling), select an available time slot based on their region, and receive WhatsApp confirmation — all without leaving the app.

Built as a 6th-semester Software Engineering (RPL) team project using **Laravel 11**, **Blade**, **Bootstrap 5**, **SQLite/MySQL**, and the **Google Gemini API**.

## My Role: AI Dirt Analysis Integration

My personal contribution to the team was building the **AI Dirt Analysis** feature — the part that lets customers upload a photo of their vehicle before booking. My work connected three layers end-to-end:

- **Frontend capture** — Wired up the photo upload step in the booking form so customers could optionally submit an image of their car.
- **Gemini API integration** — Implemented a `GeminiService` that sends the uploaded image to `gemini-2.0-flash-lite` and parses the model's structured response back into the application.
- **Business logic mapping** — Translated the AI's verdict into the three business levels (**LIGHT**, **MEDIUM**, **HEAVY**) and automatically applied the corresponding price surcharge (+Rp 0 / +Rp 15.000 / +Rp 30.000) and extra service time (+0 / +15 / +30 minutes) to the booking total.

The result is a single AI-driven input — a casual photo — that quietly drives both pricing and scheduling downstream, while staying optional so customers without a photo can still book normally.

## Full Feature Set (Team Project)

**Customer Side**
- Online booking form (name, email, phone, region, date, time, address)
- Package selection: Exterior Only (Rp 60.000) / Bundling (Rp 100.000)
- Auto-filtered available time slots based on date + region
- Auto-formatted `+62` phone numbers for WhatsApp deep links
- Optional AI dirt analysis photo upload

**Admin Dashboard**
- Real-time booking list (auto-refresh every 5 seconds)
- Status workflow: Pending → Confirmed → Completed / Canceled
- Per-booking AI dirt level badges
- One-click WhatsApp confirmation with prefilled message
- Schedule, price, and booking management

## What I Learned

Owning the AI integration end-to-end taught me how to translate a vague real-world signal ("how dirty is this car?") into a clean structured output a web app can act on. I got hands-on practice wrapping an external AI API behind a service class, handling inconsistent image inputs, and making sure a model-driven feature degrades gracefully — booking still works perfectly even when a customer skips the photo entirely.
